
# 👻 Ghost in the Dataset

### Your AI-Powered Data Detective

Ghost in the Dataset is an AI-powered data analysis application that investigates CSV datasets, detects unusual patterns, and generates explanations using Google's open-weight Gemma 2B model.

## ✨ Features

- Upload CSV datasets
- Dataset overview and preview
- Missing value analysis
- Anomaly detection using Isolation Forest
- Interactive data visualization
- AI-powered investigation reports using Gemma 2B
- Download investigation results as CSV

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Google Gemma 2B
- Ollama

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd ghost-in-the-dataset
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Install and run Gemma using Ollama

Install Ollama from https://ollama.com/

```bash
ollama pull gemma2:2b
```

### 4. Start the application

```bash
streamlit run app.py
```

## 🤖 AI Model

This project uses the open-weight Gemma 2B model locally through Ollama to explain unusual patterns found in datasets.
